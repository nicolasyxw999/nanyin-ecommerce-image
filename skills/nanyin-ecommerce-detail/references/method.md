# 套图与详情页方法

先为每张定义“看完能知道什么”，再决定图数。常用顺序：商品识别→核心利益→使用场景→细节依据→规格/使用指南→品牌或服务信息。没有足够真实参数时省略规格页，不能填“待确认”作为成品。

构图表字段：asset_id、传播任务、视觉主角、景别、视角、主体位置、文字层级、留白、相邻页差异、专业步骤、依赖。系列统一配色/字体/产品结构，但可在整景、微距、流程、比例参照、真实参数表间切换。去掉标题后仍应辨识各页职责；用户要求固定模板时允许模板系列。

单张功能图可由本技能直接规划与生成。需要专门摄影、人物或修图时返回步骤建议，交协调者安排，不能自行调用另一子技能。文案从facts提炼且保留来源，比较图必须有可核验依据。

详情模块输出统一宽度。通过共享export命令生成长图、切片和总览；导出仅拼接已完成模块，不替代文字排版。不同宽度先按用户授权处理，禁止静默拉伸。检查接缝、重复标题、阅读顺序、文字可读性和切片断点。
