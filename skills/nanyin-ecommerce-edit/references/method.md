# 编辑方法

“把背景换成厨房，商品文字不动”：底图设base，允许项只有背景；锁定商品轮廓、位置、比例、颜色、印字、Logo和配件。不要顺带美化商品细节。光影调整也须限于完成背景替换所必需的范围；若会改变商品外观先明确处理。

参考文字风格图与底图分开；在图片上方加字默认在原图内部安全区叠加，不自作主张加画布或标题条。要求精确保留文字时逐字核查，未检查则not_checked，不能称完全不变。

蒙版输入只有后端明确支持时才可使用；当前自定义接口适配器拒绝专用mask参数，不能将mask当普通参考图冒充选区编辑。可选使用用户授权且环境真实提供的编辑工具，按工具规定执行；无可靠能力则说明限制并交付可执行编辑方案。

保留源图，改动保存新asset版本。对于用户明确要求本地排版的精确文字任务，可由可用排版工具完成；不自动用脚本绘制替代用户要求的模型编辑。对比商品结构、字样、颜色和区域外变化，修复只针对已发现的问题。
