# 商品信息引导

用于用户只说“我想给这款商品做一套电商图片”，或已有资料不足以完成交付时。目标是让用户提供商品事实与业务意图，设计规划由技能承担。

## 先识别已知与缺口

- 实际查看附件。只有任务说明、示例文案或参考海报时，不称“已收到真实产品图”；示例品牌和参数不当作当前商品事实。
- 从当前任务预填品牌、商品名、已给SKU、图片、Logo、规格和授权。已有Logo可直接复用；商品图、人物图、Logo、构图及风格图标明不同角色。
- 无产品图：引导提供正面图，方便时再补侧/背面、参数标签、关键配件和细节；不把全部角度设为必填。确实没有实物资料时，确认是否允许原创概念款；未获此授权，不默认设计外观。
- 有产品图：先识别可见外观，再补问影响交付的基本资料。未知的容量、材质、保温/防漏性能、认证、销量和价格，不能从图推断，也不能沿用其他任务或测试包数值。

## 如何呈现补充信息

简短说明可制作统一风格、不同职责的套图，再给一份已预填的可复制模板。模板是可选填写范围，不是开工前必须完成的问卷；删除与任务无关或已解决的项。不要只留下“图片、卖点、风格、图数”几个泛项而漏掉目标人群、场景、品牌要求和事实依据，也不要把所有字段逐项变成强制问题。

集中追问真正阻塞的缺口，其余允许“自动推荐”或留空。用户可以用自然语言回答，不要求按格式填表。已知信息充足或明确“你决定，直接做”时，不再强制展示完整表单。

```text
【商品基本信息】
品牌名称：预填已知品牌
产品名称：预填已知名称
产品图片：已有附件 / 补正面图；侧面、背面、配件和细节图方便时提供
商品状态：已有实物 / 概念款（允许AI设计外观）
规格与SKU：已确认的容量、尺寸、颜色、款式等；未知可留空

【卖点与依据】
核心卖点：最希望消费者记住的1—3点；没有可先按已知外观提炼
真实参数及来源：用户确认说明、产品说明书、包装或检测资料
必须保留：杯型等商品结构、配件、颜色、Logo及印字

【人群与使用场景】
目标人群：已知人群 / 自动推荐为视觉定位建议
主要场景：已知用途 / 自动推荐
人物需求：不需要 / 手部展示 / 模特使用 / 自动推荐
人物参考：有指定人物、穿搭或配饰时提供

【品牌与文案】
品牌Logo：使用当前任务已提供文件 / 另附文件 / 仅文字品牌 / 不需要
品牌要求：配色、字体、宣传语；没有则自动推荐
必须出现的文字：商品名、已确认参数或活动信息
不希望出现的内容：禁用词、道具、场景或视觉元素

【交付需求】
使用平台与图位：平台/站点，以及主图、详情、广告等；不确定可先说明用途
语言：中文 / 英文 / 其他
图片数量：自动推荐，或指定数量/上限
图片规格：后台要求或指定尺寸；没有则按用途推荐
风格偏好：自动推荐 / 文字方向 / 参考图
执行方式：先出方案 / 资料齐全后直接生成整套
```

预填时用实际已知内容代替提示语，不把“预填已知品牌”原样当用户资料。商品并非杯子时按品类换掉杯子示例；品牌与Logo沿用当前任务，不将南殷或任何其他示例品牌设为所有任务默认。

“自动推荐”的范围是图数、风格、图位、视觉定位、场景和文案表达等设计选择；推荐人群只记作定位假设，不当成已验证市场数据。产品事实与销售承诺不自动补造。平台未知时可按普通品牌介绍规划，不擅自选择平台并保证上架合规。出现活动价、期限或赠品但缺条件时，只核实与该任务有关的缺口。

## 收到回复后

1. 合并当前任务已有资料，区分已确认事实、图中观察、设计建议与未知项；冲突仅针对冲突点核实。识别摘要保持简洁，不让用户重复抄表。
2. 主动提出适合用途的视觉方向与整套图位。每张说明传播职责、文案依据和构图差异；用户无需自写分镜或提示词。没有足够参数则省略参数页，没有可靠性能依据则不做性能结论或对比页。
3. 只有“先方案”或真正阻塞的事实/参考/授权缺口时，停在对应节点。用户已经要求制作且资料足够时，说明采用的推荐方案后在已授权范围连续执行，不新增逐张审批。不将自动设计授权扩展为外部付费服务、自动发布或无限修复。
4. 若用户要成图，交付实际图片、所用提示词、文件清单及检查边界；不能整理完资料后只交整套提示词就算完成。遵守共享执行指南的后端选择、提交上限、恢复与版本规则。

## 典型判断

- 只说“我想为南殷保温杯做一套电商图片”，无附件：预填已给品牌与商品名，先引导给产品图/说明没有实物，提供可选补充模板；不得假设测试用420mL、旧商品图或历史保温参数就是本次商品资料。
- 商品图、事实、受众和“风格与图数你定，直接做”均已给出：整理识别摘要、自主规划并生成；不重新索要品牌或让用户先确定逐图构图。
