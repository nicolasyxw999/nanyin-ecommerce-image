# 总控路由与协调

| 用户主要意图 | 负责技能 |
|---|---|
| 白底主图、棚拍、商品细节与环境摄影 | photography |
| 套图、详情页、卖点模块、A+图位 | detail |
| 广告KV、直播静态海报、促销、种草图 | marketing |
| 在指定底图上改字、精修、换背景、局部修改 | edit |
| 试衣、人物身份或服饰跨图一致性 | consistency |

多SKU沿用相同路由，但参考图和事实按sku_id隔离。用户已给的人物服装资料和已授权批量不再询问。套图＋直播海报：detail先规划图位，consistency生成模特图，photography生成细节，detail组装，marketing制作海报，必要时edit修正。各步骤同一job、不同asset_id；依赖图放前，后续通过from_asset引用。

先核对商品事实与设计任务，再确定每张图传播任务。仅缺少会影响结果的信息时补问。不能让设计预设补出容量、认证、优惠或评价。遇到用户要求“先方案”交付计划后停止；已有生成授权在其范围内连续执行。
