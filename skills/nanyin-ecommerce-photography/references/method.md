# 摄影方法

先定义展示目的：识别商品用完整主体；证明工艺用微距；理解体积用已知尺度参照；表达使用环境用场景图。看不到的背面、接口或内部结构不当作事实补画，需要真实参考，否则说明为概念角度。

| 方向 | 光线/空间 | 适用与限制 |
|---|---|---|
| 极简棚拍 | 大面积柔光、干净接触阴影 | 清楚呈现形状，避免过曝丢边 |
| 科技感 | 受控轮廓光、清晰边缘、少量冷色 | 只表现真实结构，不虚构屏幕功能 |
| 温和生活 | 自然窗光、生活尺度、柔和材质 | 道具不遮主体，场景符合用途 |
| 高端质感 | 克制配色、反射面与局部高光 | 金属/玻璃反射连续，不能凭视觉宣称材质 |
| 自然风 | 日光、木石与植物点缀 | 环保与有机认证仍需事实支持 |

提示词写明主体、视角、焦点、景深、光源方向、背景、阴影、保留项及输出尺寸。拍摄角度变化必须与原始参考一致，生成母图不能替代商品原图。验收看数量、接口、开孔、文字、比例和接地阴影。需要人物身份控制，返回交接给总控安排consistency。
